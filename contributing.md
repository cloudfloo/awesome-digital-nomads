# Contribution Guidelines

Suggestions are what keep this list alive — the whole point of this repo is that
pull requests actually get reviewed and merged. Aim: response within a week.

## Adding a resource

- One suggestion per pull request.
- Format: `- [Name](https://url/) - Description starting with a capital, ending with a period.`
- Add your entry to the **bottom** of the relevant section.
- Use the clean HTTPS URL — no affiliate codes, no tracking parameters.
- Write the description yourself and keep it factual: what it does and why a
  nomad would care. No superlatives.
- The resource must be alive, maintained, and useful to location-independent
  people in general. Single-destination promo pages and thin affiliate sites
  will be declined.
- You may submit your own product — say so in the PR description. Same quality
  bar applies.

## Fixing things

Dead links, renamed products, and stale descriptions are flagged by a weekly
automated check, but human PRs beat robots. Removals are as welcome as additions.

## Review

CI runs a link check and `awesome-lint` on every PR. Green CI + on-topic = merged.
